# folium

FrontEnd para la aplicación web *folium*

## Primeros pasos
Clonar repo
```
git clone git@github.com:Facundo177/folium-web-app.git
```

Para iniciar proyecto en local
```
npm install
npm run dev
```

Para interrumpir la ejecución del servidor local
*Ctrl + c* en la terminal
